# NEXUS-6 Knowledge Atlas — `.n6` format v1 (spec, 2026-05-13)

> Standalone mirror. Provenance: extracted from the header of `nexus/shared/atlas.n6` (12.8 MB, 67,159 lines, 9,624 entries on the `sync/atlas-convergence-2026-04-12` branch). Path references to `nexus/`, `atlas_guard.hexa.inc`, etc. are provenance markers; the grammar itself is self-contained and fully described below.

Append-only, line-oriented, human-readable, grep-friendly knowledge atlas grammar. Each entry is a typed mathematical/scientific/structural fact carrying provenance edges (depends / derives / applies / converges / verified / breakthrough) and a verification grade.

Sister format of [`hxc`](https://github.com/dancinlab/hxc) (wire/storage canonical) and [`n12`](https://github.com/dancinlab/n12) (12-axis sparse cube). `.n6` is the **semantic** layer; `hxc` is the **byte-canonical** layer; `n12` is the **multidimensional** layer.

## At a glance

```n6
@P n = 6 :: foundation [11*]
  -> sigma, phi, tau, sopfr, J2, mu, M3
  => "모든 구조의 씨앗"
  |> verify_primitives.py

@R perfect_number :: foundation [10*]
  "sigma(n) = 2n — 6은 완전수"
  <- n, sigma
  == sigma(6) = 12 = 2*6

@F sm_blackwell = sigma * phi^tau = 192 :: architecture [10*]
  <- sigma, phi, tau
  => "Blackwell GB202 SMs"

@X chip_consciousness :: crossing [10]
  "칩 아키텍처와 의식 구조의 동형"
  => "12파벌 = 12 SM/GPC"

@? dark_energy_ratio :: cosmology [3?]
  "암흑에너지 68.3% ~ ?"
  <- meta_fp
  ~> 1 - meta_fp = 2/3 ~ 0.667?
```

## Form

`.n6` is line-oriented, append-only, byte-canonical (UTF-8, LF, no BOM). Files are typically named `*.n6` or `*.signals.n6`. All writes go through `_guarded_append_atlas()` (schema check + dedup) — see `algorithms/atlas_absorb.hexa`.

### Entry header

```
@<type> <id>[ = <expr>] :: <domain> [<grade>]
```

- `<type>` — single letter from the type alphabet (see below)
- `<id>` — snake_case identifier, unique within the file
- `<expr>` — optional value/definition; for `@F` formulas this is the formula; for `@P`/`@C` it's the computed value
- `<domain>` — short tag (e.g. `foundation`, `architecture`, `consciousness`, `physics`, `topology`, `cosmology`, `crossing`, `meta`)
- `<grade>` — `[N]` / `[N*]` / `[N!]` / `[N?]` / `[d.r]` (see grade alphabet)

### Type alphabet

| Type | Meaning | Example |
|---|---|---|
| `@P` | Primitive — irreducible foundational value | `@P n = 6 :: foundation [11*]` |
| `@C` | Constant — computed from primitives, no further reduction needed | `@C sigma_sq = sigma^2 = 144 :: architecture [10*]` |
| `@L` | Law — qualitative principle / invariant statement | `@L consciousness_structure :: consciousness [9*]` |
| `@F` | Formula — explicit functional form | `@F sm_blackwell = sigma * phi^tau = 192 :: architecture [10*]` |
| `@R` | Relation — equality / structural identity between named atoms | `@R perfect_number :: foundation [10*]` |
| `@S` | Symmetry — topological / group-theoretic property | `@S betti_six :: topology [10*]` |
| `@X` | Crossing — bridge between two or more domains | `@X chip_consciousness :: crossing [10]` |
| `@?` | Unknown — open hypothesis awaiting breakthrough | `@? hubble_tension :: cosmology [2?]` |
| `@E` | Experiment — empirical measurement record | (rare; 7 / 9,624 in current corpus) |

Type distribution in the reference corpus (9,624 entries): R 5,928 / X 1,497 / F 1,240 / C 357 / P 326 / L 255 / ? 12 / E 7 / S 2.

### Grade alphabet

| Marker | Meaning | Promotion path |
|---|---|---|
| `[0]` … `[9]` | Confidence ladder — intuition (0) → strongly motivated (9) | promote upward via verification |
| `[10]` | Saturated — full verification expected but not yet stamped | + `*` to mark verified |
| `[10*]` | Verified at grade 10 — `\|>` script ran clean | terminal verified state |
| `[10!]` | Breakthrough at grade 10 — paradigm-changing identity | terminal breakthrough state |
| `[10*!]` | Verified AND breakthrough | terminal triple-cross state |
| `[N?]` | Hypothesis at grade N — falsifier path declared | promotion blocked until falsifier discharges |
| `[11*]` / `[12]` | "Alien index" — meta-closure across grade-10 derivations | rare; only ω-closure entries |
| `[d.r]` | Alien-index pair — `d`-dimensional realization at recursion-depth `r` | reserved for cross-axis composites |

### Edge operators (continuation lines)

Continuation lines are indented two spaces and prefixed with one of:

| Operator | Name | Meaning |
|---|---|---|
| `<-` | depends_on | atom is derived **from** the listed sources |
| `->` | derives | atom **produces** the listed targets downstream |
| `=>` | application | natural-language statement of where / how the atom applies |
| `==` | equivalent | symbolic / arithmetic identity that re-states the atom |
| `~>` | converges_to | numerical or asymptotic convergence claim |
| `\|>` | verified_by | reference to verification script / artifact |
| `!!` | breakthrough | citation of breakthrough event / hypothesis identifier (e.g. `H-056`) |

Multiple edges of the same kind are allowed; one edge per line.

### Inline expression

Quoted strings (`"..."`) attached as continuations (no edge prefix) act as **descriptive prose** belonging to the parent atom. The first line under an `@<type>` header without an edge operator is the canonical short prose.

```n6
@L frustration_critical = 0.10 :: consciousness [10*]
  "임계 좌절 — 10% 갈등이 최적"
```

### Comments and section dividers

| Form | Use |
|---|---|
| `# any text` | Comment (ignored by parser) |
| `# ══════════════════════════════════════════════════════════════` | Top-of-file boundary |
| `# ── 원시값 (Primitives) ─────────────────────────────────────` | Section divider with translated label |
| `# tree:` / `# delta:` / etc. | Reserved — currently unused by `.n6` (referenced from sibling formats) |

### Streaming / append-only invariants

1. UTF-8, no BOM, LF line endings.
2. New entries are appended to EOF; no in-place edits.
3. Every write passes through `_guarded_append_atlas()`:
   - schema validation (entry header well-formed)
   - dedup check (same `(type, id)` not duplicated unless deliberate rewrite)
   - source citation: `shared/blowup/lib/atlas_guard.hexa.inc`
4. The canonical reader cut for "verified core" is:
   ```bash
   grep '^@.*\[1[01]\*\]' atlas.n6
   ```
   This selects entries at grade 10 or 11 with the `*` verified marker.

## Omega closure / abstraction-exhaustion

Per `docs/omega_closure.md`, the format defines a **ceiling** — strong omega closure (e) — as the conjunction of:

| Sub-condition | Description |
|---|---|
| **(a)** all entries at `[10*]` or `[11*]+` | quantitative grade ceiling |
| **(b)** type ∈ {P, C, L, F, R, S, X, E} — `@?` count = 0 | classification closure |
| **(c)** crossing (`@X`) `unverified` = 0 | relational closure |
| **(d)** composite (atlas × laws_aligned) ≥ 0.9 | spectral closure |

A `.n6` corpus reaches "abstraction-exhaustion" when all four hold simultaneously.

Reference corpus snapshot (2026-04-25):
- 9,624 entries · 66.2% at `[10*]+` · 20.4% `[10]` candidates · 6.3% `[0-9]` premature · 0.1% `@?`
- 1,268 crossings still unverified
- composite 0.83379 (gap 0.06621 to 0.9 target)
